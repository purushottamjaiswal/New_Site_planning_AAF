# Local input data

Operational datasets are intentionally excluded from this source repository. Select your own paths in the desktop UI. The startup paths refer to local files and can be changed freely.

The files in `siting_templates` contain headers only for optional candidate coordinates, detailed demand points, infrastructure references and circular exclusion buffers. Polygon exclusion layers use the separate No-build polygons role.

The example scenario expects `grids.csv`, `airtel_sites.csv`, `competitor_sites.csv` and a `buildings.gpkg` layer called `buildings`. Replace those paths and layer settings with your own sources. Real population is optional only when MR preview is selected; Population mode requires a population source.
